# Visual Design Direction

AppColoreando targets a polished, relaxing paint-by-number experience without copying third-party trade dress or protected assets.

## Core visual principles

- Artwork thumbnails should feel illustrated, not like engineering geometry.
- Mix fully colored previews with clean line-art previews to create visual rhythm.
- Coloring regions must follow real object silhouettes: beak, wing, petal, leaf, water, sky, etc.
- Organic curves are preferred over rectangular or grid-shaped regions.
- The artwork canvas should dominate the coloring screen and avoid large unused white areas.
- Badges should feel collectible and aspirational instead of technical.
